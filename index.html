Run live checks against the web app

Each click sends a real HTTP request from a Vercel server to this site and records the real status code and response time.

Charts show the last 3 minutes in 5-second steps. This is the same idea as the metrics charts pinned to an Azure dashboard.

Query the logs

A small version of Kusto Query Language (KQL). Table: AppServiceHTTPLogs. Columns: TimeGenerated, CsMethod, CsUriStem, ScStatus, TimeTaken (ms), Region.

Supported: where Column ==, !=, >, >=, <, <=, contains Value   summarize count() by Column   project A, B   take N

Alert rule: alert-http-4xx-errors

Condition: total HTTP 4xx errors in the last 60 seconds is greater than the threshold. (Real Azure uses a 5-minute window; 60 seconds here keeps the demo quick.) When true, the action group sends a notification (on-screen banner and webhook).
